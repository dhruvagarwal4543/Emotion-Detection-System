# AI Emotion Detection System - Python dependencies
#
# Requires Python 3.10 or newer (tested on 3.12.13, macOS 15 / Apple Silicon).
#
# IMPORTANT - do not use Python 3.9 on macOS.
# Python 3.9 caps numpy at 2.0.2, and that specific build links against Apple's
# Accelerate BLAS in a way that segfaults inside librosa (chroma_stft and yin
# both crash the interpreter). numpy >= 2.1 requires Python >= 3.10, which is
# why the floor below is set where it is.

# --- web framework ---
Flask>=3.0,<4.0

# --- numerical core ---
numpy>=2.1,<3.0

# --- facial emotion detection (YuNet face detector + FER+ classifier) ---
opencv-python-headless>=4.10
onnxruntime>=1.19

# --- speech emotion recognition ---
librosa>=0.10.2
soundfile>=0.12
scikit-learn>=1.4
joblib>=1.3
scipy>=1.11

# --- PDF emotion report ---
reportlab>=4.0

# NOTE: merging the video and audio tracks into one MP4 needs the ffmpeg
# binary, which is not a Python package. Install it separately:
#     brew install ffmpeg
# Without it everything else still works; only the merged MP4 is skipped.
